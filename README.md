🛍️ Daraz Homepage Clone

A frontend practice project focused on recreating the Daraz homepage using HTML5 and CSS3.

📌 About the Project

This project is part of my frontend web development learning journey. The goal is to recreate the layout of the Daraz homepage and improve my understanding of HTML structure, CSS styling, and responsive web design.

🛠️ Technologies Used

- 🌐 HTML5 — Structuring the webpage
- 🎨 CSS3 — Styling and layout

📂 Project Structure

daraz-homepage-clone/
├── index.html
├── style.css
├── Images/
│   └── image.jpg
└── README.md

✨ Features

- 🧭 Navigation bar
- 🔍 Search bar
- 🖼️ Homepage banners
- 📦 Product categories
- 🛒 Product cards and sections
- 📱 Responsive layout
- 🎨 Daraz-inspired design

🚧 Features will be implemented progressively as the project develops.

🎯 Learning Objectives

- 🧱 Practice writing semantic HTML
- 📐 Improve CSS layout and positioning
- 🧩 Learn Flexbox and CSS Grid
- 🖼️ Understand image paths and asset management
- 📱 Practice responsive web design
- 💻 Build a real-world-inspired e-commerce interface

🚀 Getting Started

1. 📥 Clone the repository:
   
   git clone https://github.com/chaudharysajid007/daraz-homepage-clone.git

2. 📂 Open the project directory:
   
   cd daraz-homepage-clone

3. 🌐 Open "index.html" in your browser.

4. ✍️ Edit "index.html" and "style.css" to continue development.
